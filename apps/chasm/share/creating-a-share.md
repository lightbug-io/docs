# Creating a share

## Admin portal

Data can be shared from supported devices [via the admin portal](/apps/admin/devices/sharing). Open the device's **More actions** menu and choose **Shared access** under **Connectivity**. Check the device shown in the dialog, then choose the message type and time period to share.

The dialog defaults to **Last 1 hour** in your local timezone. Use **Quick time range** or edit the start and end times to select a period of up to **24 hours**. See [time selection](/apps/admin/devices/sharing#time-selection) for UTC/local input and supported paste formats.

![Share device data dialog showing the selected device and time range =800x](https://upload.r2.lb.chasm.cloud/2026/11/screenshots/devices-share-e9133f54-4ec8-4685-82b8-f36315c36862.png)

Click **Share**, then use **Copy** or **Open share**. Anyone with the link can view the shared data without signing in.

## Message headers

It is also possible to open up V3 messages to the share system by adding a custom header to the message when sending it to the chasm.

For more information on how to do this, please contact us.
