# How to extract raw location data

**`Target Audience:`** First time users  
**`Difficulty:`** Easy  
**`Prerequisites:`** A Lightbug account and access to the mobile app or web portal

## Guide

1. Open the `Lightbug App` or go to the [Web Portal](https://lightbug.cloud/)  


2. On `'Map'`, select the tracker from the drop down box  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043206436909/original/4ZM3DoFtJUQqOLvbiia27tSiNwSSh9-RXQ.png){width=250}  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043206437526/original/svrdWVTEQIYZrmg0oemd5KCa6b4r6uttsQ.png){width=250}  

3. `Select the time period` of the data  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043206438630/original/ioz6F9pZJ1AHwo3ejZbdbXPc6RKyoJ3h5A.png){width=250}

4. Click the `drop down arrow` and then the `export symbol`  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043206441176/original/i61kxlBncvvWVWJ-Txl8lqIsdE42zIMaSQ.png){width=250}  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043206441298/original/mRocG-2-YZEa4mkz0EuE3wJ5juy01HVVEw.png){width=250}  

5. `Choose the format` you would like to export the data  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043206443238/original/33mB8uKAmyek6GHdAf80gPYU3qnMRPigfA.png){width=250}

The file will automatically download to your device.
