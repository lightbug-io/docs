# How to create a home Wi-Fi safe-zone

- **Target Audience**: First time users  
- **Difficulty**: Easy  
- **Prerequisites**: A Lightbug account and access to the mobile app or web portal  

## Guide  

The benefit of setting up a `home Wi-fi safe zone` over a `GPS safe zone` is that the device will check approx. `every 5 minutes` whether the device is in range of the `Wi-Fi`. If the device `is not`, you will be sent a `notification`. Whereas, if the device leaves the `GPS safe zone`, the notification will be sent at the `next location update`.  

To set up your `home Wi-Fi safe zone`, follow the steps below:  
1. On the app go to Menu - select `'Tracker Settings'`  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043111920113/original/foz-C1QXpFs-mTIVWZQP2Fj-TtZv1cT_vA.png){width=250}  

2. Step `2/7`: `'Operation Mode'` - select `‘Motion Tracking’`  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043082781780/original/q9byPvZxCotJvyBZR7IUxA4Nc75qX1hIUQ.png){width=250}  

3. Step `3/7`: `‘Home Wi-Fi Safe-Zone'` - enter your home Wi-Fi details  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043082781781/original/6WmU8KgpAeUxdqr3vlWeTrnylFRADcM-2A.png){width=250}  

4. Step `5/7`: `‘Wake Mode’` - select the `location update rate` for when the device is moving `out of range` of the `home Wi-Fi`  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043082781779/original/7lLMm7DaWYelyKM2ayuX9xUQ3P9DRzSlpg.png){width=250}  

5. Step `6/7`: `‘Sleep Mode’` - select the `location update rate` for when the device is `nearby` the `home Wi-Fi`. Select `'Save’`  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043082781782/original/uePlGflUOCC00h7HaVLsvmpkqkoHOs1uFQ.png){width=250}  

Your `home Wi-Fi safe zone` is now been set up.  
::: info
**You will need to be on the Unlimited Data Plan (as this allows for motion detection) to use this feature.**
:::  
::: info
**To apply the new settings immediately, press the button on your tracker. If you don't have your tracker to hand, the tracker will update its settings the next time it is scheduled to send a location update.**
:::
