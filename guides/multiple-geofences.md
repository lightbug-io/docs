# How to Create Additional Safe-Zones 

- **Target Audience**: First time users  
- **Difficulty**: Easy  
- **Prerequisites**: A Lightbug account and access to the mobile app or web portal  

## Guide  

If you have not set up your first safe-zone (geofence) through the 'Tracker Settings' setup wizard, you can find out how to do so [here](/guides/gps-geofence.md).  

1. On the app go to `Menu - 'Alerts'`  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043111904586/original/jh37AZTHn82hkcZHRWKWmPWqiqH1OPTpkw.png){width=250}  
2. Select `'Create New Alert'`  
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043111905157/original/-6INgjfJ7UTzgjkTKz7IzI-dzYyI5eUraw.png){width=250}  
3. On the popup page complete the following:  
    **`Alert name:`** here you should choose the most `appropriate name` for your safe-zone, this name will be displayed on `every notification` you get for this alert.
    For example: 'Work Safe Zone', 'School Safe Zone', 'Home Safe Zone'.  
    ![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043111905801/original/j4oNsiehumRd8Cwy1LUHOpHPpub5DHLX7w.png?){width=250}  
    **`Alert Type:`** select `'Geofence'`, `'Define Geofence'`  
    ![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043111914419/original/rbbRql25-XaA3G26ZsMHG6j-LsS2hg2GrQ.png){width=250}  
    **`Safe-zone setup map:`** `Tap the map` to create your safe-zone area and select `'save'`  
    ![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043111915660/original/6huvwZI98oc1Xcy2lAr55GYniqezWTiZRw.png){width=250}  
    **`Delivery Type:`** Select how you would like to `receive the alert`  
        - `Enabling Email alerts` will allow you to set `which email` you would like to `receive the alerts on`.  
        - `Enabling Push to phone` will send alerts in the form of `notification to your smartphone`.  
    ![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043111916843/original/xtbflt3l7rpsvcmYnngIkH_aAaIdUDVJ5A.png){width=250}  
    **`Mute this Alert for:`** If you would like to `mute` your alarm after a `certain period` of time once being `triggered`, you can do so here. This step is not mandatory.  
    ![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043111917204/original/RbS0ZtTyfNUezhYh189LT11mQTVX-u2v1g.png){width=250}      
4. `Review the page` to make sure you are happy with the new alert and then select `'save'`.
![](https://s3.amazonaws.com/cdn.freshdesk.com/data/helpdesk/attachments/production/2043111918290/original/O0FCNbNYSogOzLQWAOxSTnxjgHsBayQYeQ.png){width=250}  

::: info
**Repeat these steps for additional safe-zones.**
:::  
::: info
**In order to use this feature you will have to be on the `Unlimited Data Plan` as it allows for
motion detection.** 
:::  
::: info
**To apply the new settings immediately, press the button on your tracker. If you don't have
your tracker to hand, the tracker will update its settings the next time it is scheduled to send a
location update.**
:::
