Pro ​

The current Pro is Pro3 (PR3), a different hardware generation from ProN (PR2). The two generations share the same external appearance, so use the product code and hardware revision to identify your device before following its instructions. ProN (PR2) is now a legacy model and is no longer in production.

Feature guides ​

Selected shared features, with more guides to come. This is not a complete feature list.

  • Four power LEDs ↗

LED indicators ​

The four power LED capability defines the normal battery and charging patterns. On revisions 02–04 these indicators are orange. They are also used during startup and for alerts, so four lit indicators are not always a battery reading.

There is no separate GPS/mobile-network colour table on Pro3. The older PR2 example of two red and four orange lights is not this model’s layout. Use the LED guide for the first checks when a pattern is unfamiliar.

Charging ​

Use the charging accessory and power supply specified for your Pro3 revision, within the Pro3 charging limits. The actual charge rate depends on the input source, battery and thermal conditions. Do not apply PR2 voltage/current ratings or charging-time instructions to Pro3.

See four power LED charging patterns for the normal blinking and steady states. A steady high-charge display is not an exact 100% reading.

Specifications ​

The overview, tables and PDF use the same Pro3 specification. Optional sensors and features requiring compatible firmware are labelled in the tables. Component specifications describe the individual parts, not additional finished-product guarantees.
