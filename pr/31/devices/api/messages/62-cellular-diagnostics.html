62: Cellular Diagnostics ​

Runtime cellular-module, upload-buffer, and internet-link diagnostic state. GET returns NotSupported when cellular diagnostics are unavailable on the device. Upload-buffer and primary-link values are zero when their runtime objects are absent. Secondary-link fields 13-15 are omitted when that link is unavailable. RX/TX counts belong to the primary and secondary internet links, not the UART used to request diagnostics. They count V3 messages, not bytes or cellular network packets. RX increments after protocol, length and checksum validation in the receive path, before message handling. It is not a count of unique messages or successfully executed commands; repeated frames count again. TX increments for each message send request, before queuing or sending, including requests that are later dropped or fail. Uploading or retrying buffered data does not itself increment TX again. Control messages, including ACKs and heartbeats, count when they use these same paths. Each counter starts at zero when its link object is created (normally at boot), survives link reconnects and diagnostic GETs, and wraps from 4294967295 to zero. These are link-object lifetime counters, not per-session totals.

Header ​

FieldNameDescriptionType
5MethodRequest a service to be perform an action
Possible values:
  • 1: SET— Set one or more values that are provided in the message payload.
  • 2: GET— Get values for the associated message type.
  • 3: SUBSCRIBE— Subscribe to values for the associated message type. Can be used in conjunction with other header fields to define the subscription parameters, such as Interval, Duration, Timeout, Storage Level and Message Level. If no interval is provided, messages will be sent as and when new data is available. Some data, such as GPS position, may require a set interval to be provided.
  • 5: UNSUBSCRIBE— Unsubscribe from a previous subscription.
